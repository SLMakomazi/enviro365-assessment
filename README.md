Enviro365 Assessment Repository

Overview

This repository contains a simple full-stack assessment project (Enviro365) with a Java Spring Boot backend and a Vite + React frontend.

Top-level layout

- README.md (this file) — repo overview and how-to.
- backend/ — Maven Spring Boot backend service.
- frontend/ — React + Vite frontend application.

Backend (backend/)

- pom.xml — Maven project file. Defines Java and Spring Boot versions, dependencies, and build plugins.
- src/main/java/com/enviro/assessment/junior/siseko_makomazi/
	- AssessmentApplication.java — Spring Boot entrypoint (main class).
	- config/
		- CorsConfig.java — CORS configuration for the MVC layer.
	- controller/
		- InvestorController.java — REST endpoints for investors.
		- PortfolioController.java — REST endpoints for portfolios.
		- WithdrawalController.java — REST endpoints for withdrawals.
	- dto/
		- InvestorDTO.java — Data Transfer Object for investor data.
		- PortfolioDTO.java — DTO for portfolio data.
		- WithdrawalRequestDTO.java — DTO for withdrawal requests.
		- WithdrawalResponseDTO.java — DTO for withdrawal responses.
	- exception/
		- AgeRestrictionException.java — custom runtime exception used when validations fail.
		- InsufficientBalanceException.java — thrown when balance insufficient.
		- GlobalExceptionHandler.java — @ControllerAdvice centralizes handling exceptions and mapping them to responses.
	- model/
		- Investor.java — JPA entity model for investors.
		- Portfolio.java — JPA entity model for portfolios.
		- Product.java — (if present) model for product items stored in a portfolio.
		- Withdrawal.java — entity representing a withdrawal request/record.
	- repository/
		- InvestorRepository.java — Spring Data JPA repository for Investor.
		- PortfolioRepository.java — repository for Portfolio.
		- WithdrawalRepository.java — repository for Withdrawal.
	- service/
		- InvestorService.java — business logic for investor operations and DTO mapping.
		- PortfolioService.java — business logic for portfolio operations.
		- WithdrawalService.java — handles withdrawal validation and persistence.
	- validation/
		- WithdrawalValidator.java — performs custom validation rules for withdrawals.

- src/main/resources/
	- application.properties — Spring Boot configuration (server port, datasource, H2 console if enabled, etc.).

- target/ — build output. Contains compiled classes, resources, and packaged jar. Do not commit this folder.

How to run (local development)

Backend

Requirements
- JDK 17 installed (Maven runs with Java 17 in this repo configuration).
- Maven installed (or use IDE build integration).

Commands

To compile and run backend:

```bash
cd backend
mvn spring-boot:run
```

Or build a jar and run it:

```bash
cd backend
mvn clean package
java -jar target/enviro365-backend-0.0.1-SNAPSHOT.jar
```

Frontend

Requirements
- Node.js (LTS recommended)

Commands

```bash
cd frontend
npm install
npm run dev
```

Notes and troubleshooting

- The `target/` directory is generated by Maven and should not be committed.
- If your IDE reports stale Java analysis warnings after you modify the Maven config or sources, try:
	- Reload window in VS Code (Command Palette → "Reload Window")
	- Java: Clean the Java language server workspace / Restart the language server
	- Reimport the Maven project in your IDE

- The backend in this repo is configured to use H2 (in-memory) by default; check `application.properties` for datasource and server settings.

- Tests: run with `mvn -f backend/pom.xml test`.

Where to look first (for assessment reviewers)
- `backend/src/main/java/.../controller` — API surface.
- `backend/src/main/java/.../service` — core business rules and mapping logic.
- `frontend/src/pages` and `frontend/src/components` — UI and workflows.
